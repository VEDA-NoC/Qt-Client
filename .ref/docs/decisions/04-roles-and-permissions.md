## 공통 보안 규칙

- 기본 거부 원칙으로 서버에서 권한을 검사한다. UI 비활성화만으로 권한을 보호하지 않는다.
- 위험 제어, 사용자 변경, 저장장치 초기화, 영상 내보내기는 모두 감사 로그를 남긴다.
- 운영자와 관리자는 공용 계정을 사용하지 않는다.
- 로그인 실패 제한, 비밀번호 정책, 세션 만료, 강제 로그아웃을 둔다.
- 향후 현장 요구가 생기면 역할을 늘리기보다 `fire_response`, `video_export` 같은 capability를 역할에 매핑한다.

## 후속 구현 시 검토

- 2인 승인 또는 재인증이 필요한 위험 작업 범위 / 기능 구현 이후 논의.
- 사용자 계정은 1차 버전에서 서버 로컬 DB로만 관리한다.
