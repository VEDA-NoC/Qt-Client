## 외부 또는 실장 검증 대기

- CCTV SUNAPI 2.6.6과 참고 문서 2.6.8은 우선 호환으로 가정하며 문제 발생 시 모델·버전 차이를 진단한다.
- 카메라 LPR 앱 지원과 번호판 이벤트 정확도·필드를 확인한다.
- 자동차365 또는 대체 공식 API가 번호판 기반 전기차 분류를 어떤 동의·계약 조건으로 제공하는지 승인 과정에서 확인한다.
- 500 GB HDD는 배송·장착 후 filesystem, SMART, 쓰기 성능과 보존 정책을 검증한다.
- STM32F401RE 보드 리비전과 LSE 실장 여부, 방재판·스프링클러 완료 피드백을 확인한다.

위 항목은 Qt M3 UI 셸 구현을 차단하지 않는다. 미연결 상태와 실패 상태를 먼저 UI에 명시하고 실제 API가 준비되면 교체한다.

- 영상 내보내기 형식, 워터마크, 암호화, 반출 승인 절차 (기능 구현 이후 고려)
- 소프트웨어 자동 업데이트와 코드 서명 (우선순위 마지막으로 고려) 
- Raspberry Pi DB·설정·인증서 백업 및 복구 (기능 구현 이후 고려)
- HDD 추가 시 새 녹화 배치 정책 (기능 구현 이후 고려)
- 충전 스테이션 프로토콜과 충전 완료 판정 (STM 담당자 및 해당 기능 구현 이후 고려)
- 알림음, 팝업, 이메일 등 외부 알림 채널 (이메일 제외)
- 다중 모니터 지원과 전체 화면 채널 전환 (기능 구현 이후 고려. 1화면으로 우선 간주)

## 빠지기 쉬운 운영 결정

- 정전 시 MP4·SQLite를 안전하게 종료할 UPS와 graceful shutdown 정책
- Raspberry Pi 또는 HDD 교체 시 장치 identity와 설정 복원 절차
- DB schema와 프로토콜 버전 upgrade/rollback 정책
- 인증서 발급·갱신·폐기와 초기 장치 pairing 절차
- 방재판·스프링클러를 실제 작동하지 않고 검증하는 훈련/점검 모드
- 장애 신고용 진단 bundle 생성 시 영상·차량번호를 제외하는 규칙
- 감사 로그와 제어 이력의 별도 보존 기간 및 위변조 방지
- 서버 재부팅 후 진행 중이던 이벤트·명령의 상태 복구
- 카메라 장면 변경 후 주차 구역 polygon 재설정과 calibration 절차 (기능 구현 시 필요함)
- 설치 현장별 site/zone/channel 이름과 설정 백업·가져오기
